# Jinju Kim

기업·금융 데이터를 분석하고, 전문가가 근거를 확인할 수 있는 AI 업무 흐름으로 구현합니다.

## Focus

- Financial and corporate data analysis
- Machine learning and explainable AI
- LLM-based workflow automation
- Reproducible modeling, validation, and documentation

## Selected Work

### Industry code classification AI Agent

합성 데이터를 사용해 관리자 배정, 작업자 AI 후보 분류, 검수자 승인과 재작업으로 이어지는 검토 가능한 업무 흐름을 구현했습니다. 후보 코드와 판단 근거, 기업 활동 원문, 검수 결과와 변경 이력을 함께 제공합니다.

- [nice-industry-code-ai-agent-demo](https://github.com/kjj403/nice-industry-code-ai-agent-demo)

### Lending portfolio optimization

대출 데이터의 비대칭 손실을 반영한 비용 민감 학습과 위험 조정 수익률 평가를 결합했습니다.

- [Lending-Club-Project](https://github.com/kjj403/Lending-Club-Project)

### Customer churn analysis

공개 대체 데이터를 활용해 고객 세분화, 이탈 예측, SHAP 기반 설명 과정을 구성했습니다.

- [Insurance-Churn-Analysis](https://github.com/kjj403/Insurance-Churn-Analysis)

### AI meal recommendation service

사용자 조건과 선호를 반영하는 LLM 추천 서비스로, 외부 API를 서버리스 함수 뒤에 분리해 배포했습니다.

- [Live Demo](https://pick-my-lunch.vercel.app)
- [Repository](https://github.com/kjj403/Pick-My-Lunch)
